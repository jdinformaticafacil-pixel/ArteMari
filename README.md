# Mimo & Arcilla · web de muestra

Maqueta navegable en HTML y CSS (sin dependencias ni JavaScript) de la tienda de tazas artesanales. El nombre, la paleta y los textos entre corchetes son provisionales.

## Páginas

- `index.html`: inicio
- `producto.html`: ficha de producto
- `personalizados.html`: encargos y formulario de presupuesto

Los colores están en las variables de `css/style.css` (bloque `:root`). El formulario y los botones de carrito son solo de muestra: no envían nada.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube el contenido de esta carpeta (los archivos tienen que quedar en la raíz del repositorio, no dentro de otra carpeta).
2. En el repositorio, entra en **Settings → Pages**.
3. En *Build and deployment*, elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`, y guarda.
4. En uno o dos minutos la web estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

Las rutas son relativas, así que funciona igual bajo ese subdirectorio.

## Antes de enseñarla

- Sustituye los textos entre corchetes: `[XX] €`, `[NOMBRE DE LA MARCA]`, medidas, plazos, tu historia y los cuidados.
- Si el repositorio es público, las fotos también lo serán.
